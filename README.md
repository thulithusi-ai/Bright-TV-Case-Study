# Bright-TV-Case-Study
 To provide insights that would assist CVM (Customer Value  Management) team in meeting this year’s objective. 


 Overview
This repository contains my analysis and presentation for the BrightTV Viewership Analytics Case Study. The objective of the project was to generate actionable insights that could assist the Customer Value Management (CVM) team in achieving the CEO's goal of growing BrightTV's subscription base during the current financial year.

1. Overview

The analysis explores user behaviour, content consumption patterns, and growth opportunities using BrightTV's subscriber profile and viewing transaction data.

2.Business Objective
To provide data-driven recommendations that help BrightTV:

Increase subscriber consumption and engagement
Identify key factors influencing content consumption
Improve performance during low-consumption periods
Grow and retain the user base through targeted initiatives
